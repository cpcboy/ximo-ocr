# 墨析 OCR · DeepSeek 接手工单

日期：2026-10-23。这些是按现状整理的**待办及验收条件，不是批量执行授权**。先读 [技术交接](DEEPSEEK_HANDOFF.md) 和维护铁律；每张工单独立分支、独立 review、PR/CI/合并、逐次确认部署。接手默认只做 DS-00。工单优先级指工作顺序，不把未复现问题冒记为 P0/P1 漏洞。

## 共用交付要求

每单提交：需求/已确认口径、最小方案、文件及原因、测试原始结果、P0/P1/P2 review 与逐条处置、README/CHANGELOG/DEPLOYMENT/维护记录、commit/PR/CI、是否部署/重启、真实截图/关键路径/日志摘要、回滚步骤。权限/存储/流程新歧义先问用户。没有 reviewer 就停在待 review，不能自行扮演两名独立 reviewer。

GPU 工作只用本地合成文件或用户明确授权的测试副本，不外发真实扫描。完成单测、CI、接口检查、真实浏览器、原生 App、发布下载、Windows 目标机，是不同层级，分别记录通过/失败/未测。

## DS-00 — 接手基线与下一步确认

**优先级：第一步；状态：可做只读核对；不得自动转入下一单。**

- 目标：确认收到完整源码、读取文档、区分三个版本，给用户可执行下一步。
- 输入：本交接 ZIP + `.sha256`、仓库访问、当前机器系统/硬件信息。没有执行环境时先做文档审阅，不能伪报实测。
- 操作：核对 ZIP hash/CRC/入口；读取 AGENTS/维护铁律并复述六步；已有 clone 核对 remote/status/SHA/PR #11/公开 rc.2。若仅收到 ZIP，说明需独立新 clone，不能伪造 .git。仅读版本文件、必要的进程/端口归属；不读取业务内容，不启动生产后端。
- 需向用户确认：后续在 Mac 还是 Windows 执行；下一张工单；是否允许临时退出 App、使用多少 GPU 时间/空间；是否允许新版本打包、候选发布或本机安装（各自独立）；新候选版本号；测试样本范围。
- 验收：交付一页基线报告，列出源 `352665...`、公开包 `3e9a7e2...`、原机安装 `b7d29292...` 与实际新状态差异，明确无生产变更；推荐 DS-01 或 DS-02 并等待用户选择。
- 风险/回滚：只读无应用回滚；不能把历史 App 安装、退出或 release 授权当作新授权。

## DS-01 — 将已合并 MLX 优化纳入原生 Mac 候选并验证

**优先级：高；状态：源码完成、原生集成验收与新安装授权待确认。**

- 目标：让真实 Mac App 获得已测的缓存效率改进，不能只交源码或速度推测。
- 已有基础：PR #11 已合并；不要重写优化。模型/精度/图片切块/默认参数不变；M3 Max 五图实测详见 MLX_PERFORMANCE。
- 前置：用户确认此次构建/原生隔离测试范围；需要退出旧 App 先确认保存，安装到 `/Applications` 另外明确确认。新候选命名先确认，不覆盖 rc.2。
- 范围：从新 clone 或保全旧产物后的 clean main 构建；如需版本变更，先独立 review/PR/CI/合并；打包便携 MLX 0.29.3，不偷换开发 venv。保留旧 `.app` / DMG 和哈希；校验新包 SOURCE_COMMIT、签名、许可及无业务文件。
- 原生验收：专用新 support、确认 3000/18765 归属，合成图片与多页 PDF → 逐页完成 → 四主题阅读与表格 → 编辑/保存 → TXT/JSON/MD/完整 ZIP → 取消/刷新/正常退出；核对输出/下载 CRC、原图 hash、后台进程与 active/cache 释放。
- 质量门禁：相同模型修订/参数/输入，完整 token/文字/停止诊断与基线比较；记录冷/暖加载及各计时边界。1 GiB 不写成硬内存限额，不降低质量参数来争取速度。
- 安装门禁：全量任务均终态、稳定业务/模型清单、来源/签名/漂移通过，再使用原 deploy_macos install；只更新 App。正常目录只读核对数量和文件保全，不打开历史阅读任务做测试。
- 完成条件：原生隔离真实路径、性能/质量证据与独立 review 清零；若安装未授权，交付“候选已验、未安装”，不能登记已更新。
- 失败/回滚：不发布；获准安装后若失败，按该次 previous.app + installed-manifest.json 和全新审计目录回退，只恢复 App。不可用修改任务数据来掩盖失败。

## DS-02 — Windows 10 Pro 真实机器安装、杀毒与 OCR 验收

**优先级：高；状态：目标机器未验；必须由用户授权在那台机执行。**

- 目标：验证历史“停止 LNK 报毒”和“127.0.0.1 拒绝连接”是否在新候选仍存在，并完成平台真实路径。
- 前置：读 WINDOWS_CODEX_HANDOFF / WINDOWS_TEST_REPORT_TEMPLATE；核对 CPU、RAM、NVIDIA 型号/显存/驱动、Win10 build、Edge、杀毒产品/版本、安装器来源及 hash。硬件不兼容即报告，不承诺 CPU/AMD 可以跑当前 CUDA 引擎。
- 数据保护：优先全新测试账户/虚拟机；Mac 的 support 环境变量不能隔离 Windows 启动器。目标账户已有数据时先备份并获授权。不要先卸载旧版再临时找回退包。
- 安装/安全：标准安装→杀毒扫描→确认快捷方式仅指向 `MoxiOCRStudio.exe`；无旧停止 LNK/PowerShell 绕过脚本。若告警，记录精确文件 SHA、检测名、阶段、隔离动作；不直接定性误报，不关闭杀软/添加全盘排除、不上传含隐私文件作扫描。
- 连接诊断：逐层查本机代理、3000/18765 的 PID/命令、frontend/backend 日志、readyz、网页。区分启动失败、端口冲突、文件隔离、Edge 委派窗口、启动器提前退出；禁止对所有 node/python/msedge 批量 kill。
- 生命周期矩阵：Edge 冷启动/已有窗口、双击两次、刷新、最小化至少两分钟、关闭等待、重开；不能用 Edge 初始进程退出判断窗口关闭，不能轮询 health 来验证断开。
- 下载/OCR：用户点击官方 Windows 模型+AI 包，暂停/续传/关闭重开、完整 hash/导入探针、重启发现模型；合成图片+至少 3 页 PDF OCR，读/改/导出；任务结束/退出用任务管理器和 nvidia-smi 留显存释放证据。下载/加载互斥、损坏修复仅在隔离目录测。
- 完成条件：真实目标机报告、截图/脱敏日志、具体失败/通过项、实际包源/hash；修改先 PR/CI 合并再重新打包复验。单纯构建成功不能关单。
- 回滚：保留旧安装器/程序清单，按用户确认恢复程序，不删除 `%LOCALAPPDATA%\MoxiOCRStudio` 的模型与任务；不绕过安全拦截。

## DS-03 — 扩大无损 OCR 与生命周期回归覆盖

**优先级：高，作为后续正式版门禁；状态：五图短输出通过，长文档/重复边界未覆盖。**

- 目标：验证 MLX 优化不会在复杂长输出、取消/重试和多任务时导致丢字、重复或内存不释放。
- 数据集：自生成段落/中英混排/多栏/公式/表格/合并单元格、密集长页、多页 PDF、多页 TIFF/ZIP、不同尺寸；记录输入 hash/期望标记/参数。不得直接使用用户原书扫描目录。
- 基线：固定权重和运行时，相同输入/模式/DPI/切块/prompt/输出长度；AB/BA、冷/暖分开。保留全部 token/文字/诊断，不只比前 N 字或字符数量。
- 边界：EOS、最大长度、真实重复保护、空白/损坏页、取消加载/推理、任务终态与重试、多页部分失败；同时检查 ZIP 中原图/文本/JSON/Markdown 一致性。
- 性能：记录整页、首 token、首字后、冷加载、前端端到端、active/cache/峰值；不用系统 swap 代替本应用峰值；有退化样本如实列出。
- 完成条件：输出一致性门禁全部通过，边界失败明确关闭或阻止发布；性能改进可重现且边界明确。无权重或设备时状态保持未验。
- 回滚：仅撤回候选代码 via revert PR；不量化、不静默降 DPI/缩短输出、不禁用防重复以“通过”测试。

## DS-04 — 新双平台候选预览版发布

**优先级：在选定平台验收完成后；状态：等待用户确认新版本及分发范围；不是现在直接发 rc.3。**

- 目标：将经验证的变更放入新的 Mac/Windows 安装包，保持 Pre-release / 非 Latest；正式版另行确认和全量门禁。
- 前置：用户指定范围/版本；独立 review 无 P0/P1、P2 逐条处理；PR/main CI 成功；应用源、版本文件、发行说明一致。无 Windows 真实验收只能公开如实标注 candidate，不能写双平台全部通过。
- 实施：先归档旧产物并回读 SHA；clean HEAD==origin/main；构建两平台，检查 SOURCE_COMMIT、网页摘要、许可、签名/未签名声明和包内无数据/模型/密钥。
- 发布：使用新 tag/文件名，不覆盖 rc.1/rc.2；先 draft+prerelease+latest=false，逐个资产 hash/size 核对，公开后解析 tag 实际提交并回读资产。真实浏览器查看限制/入口并点击下载，记录拦截不得绕过。
- 完成条件：源码 SHA/CI/两包 hash/真实分发证据/未验范围/维护行齐全；本机更新不包含在分发授权内。
- 回滚：错源/错 hash/误标正式或关键路径失败立即停止公开或标撤回，保留原 tag/资产；另走修复 PR，不 clobber、不移动 tag。

## DS-05 — 首次用户体验、签名与干净机器验收

**优先级：正式版前；状态：未完成；涉及证书/费用必须另确认。**

- 目标：无预装模型/运行时/LM Studio 的新机器安装后，有清晰硬件/下载/失败提示并能完成真实 OCR。
- 测试：无模型→下载→暂停→退出→重启继续→完整校验→首次推理→导出→卸载保留数据→重装复用；低磁盘/网络中断/错误 Range/错误哈希/组件缺失应可恢复，不加载半成品模型。
- 签名：评估 Developer ID + notarization、Windows 代码签名的所需账户/证书/成本；先给用户方案。证书/密码/token 仅通过用户官方安全入口，不写文档、仓库或聊天。
- 原生诊断：分别重现 sandbox/输入法告警和真实功能；记录系统版本/时间/日志，不把“功能能用”写成“没有告警”。
- 完成条件：按平台给真实新用户路径证据和安全拦截结论；仅合成 TXT 导入不等于模型 OCR 首装验收。
- 回滚：保留旧安装器与审计；签名或安装失败停止发布；不要求用户关闭安全保护，不删除保留数据。

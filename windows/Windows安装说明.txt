墨析 OCR 工作台（Windows 10 专业版 x64）
版本：1.3.0-rc.2 candidate（尚未完成目标 Windows 10 / NVIDIA 实机验收）

安装方法
1. 将“MoxiOCR-Windows-x64-1.3.0-rc.2-candidate.exe”及对应 SHA-256 清单复制到 Windows 电脑并核对。
2. 双击安装，完成后从桌面或开始菜单启动“墨析 OCR 工作台”。
3. 点击首次使用提示“下载模型”，或打开右上角系统状态，点击“下载并配置模型”。
4. 首次配置会下载 Windows AI 运行环境和 baidu/Unlimited-OCR 模型，请保持网络畅通。
5. 支持暂停；关闭应用会暂停，重新打开后点击继续下载。文件与运行时校验完成后才能开始图片/PDF OCR。

硬件要求
- Windows 10 64 位。
- 当前 Windows 引擎需要 NVIDIA 显卡及可用的 NVIDIA 驱动。
- 模型约 6.68 GB，运行库另行下载，建议预留至少 18 GB。
- Windows 下载 baidu/Unlimited-OCR 的 NVIDIA/PyTorch 版本；Apple MLX 仅适用于 Apple Silicon Mac，不能在 Windows 使用。
- Word、Excel、PowerPoint 和 OpenDocument 文件需要另行安装 LibreOffice；
  图片、PDF、文本、多页图片和 ZIP 不需要该转换器。

文件位置
- 主程序：%LOCALAPPDATA%\Programs\MoxiOCRStudio
- 模型和运行环境：%LOCALAPPDATA%\MoxiOCRStudio
- 识别记录：%LOCALAPPDATA%\MoxiOCRStudio\data
- 日志：%LOCALAPPDATA%\MoxiOCRStudio\logs

说明
- 安装包本身不包含模型。
- 关闭应用窗口后，程序设计为停止后端与模型；本候选仍需在你的 Windows 机器核验进程与显存实际释放。
- 1.0.1 起不再创建 PowerShell“停止后台服务”快捷方式，避免杀毒软件
  将隐藏 PowerShell LNK 误判为木马。
- 1.0.2 改为按照网页心跳管理服务，不再依赖 Edge 初始进程是否持续运行，
  处理打开后出现 127.0.0.1 拒绝连接的问题；目标机器仍需实测。
- 卸载主程序不会删除已下载模型和识别记录，方便以后重装继续使用。
- 本安装包未做商业代码签名；Windows 可能显示发布者未知。
- 不建议关闭安全防护或添加排除项；遇到隔离请保留检测名称、路径和日志，交给维护者核查。
